## 2026-09 增补上线

### 权限模型收紧（admin / 部长 / 成员）
| 功能 | 状态 |
|---|---|
| 档案等级/累计时长仅 admin 与本部门部长可写；部长限本部门、不可自审、不可见他部门 | ✅ |
| 库存预警/低库存提示仅 staff；队员不可见 | ✅ |
| 队员可发起采购申请（审批仍为 admin/部长） | ✅ |
| 领用审批按申请人部门流转（无部门/无部长部门 → admin 兜底） | ✅ |
| admin-only 导航与接口：系统设置/系统日志/回收站/备份/云存储/AI 管理员、部门写、users 增删 | ✅ |
| 组织架构页：部长只看本部门；本部门内可管理账号（member↔部长、调部门），不可 admin | ✅ |
| 邀请码：部长可生成（本部门/不限）且互相隔离；admin 全量 | ✅ |
| JWT 中文角色解码修复（base64url + UTF-8） | ✅ |

### 库存 / 盘点
| 功能 | 状态 |
|---|---|
| 盘点管理权=发起者+admin；暂停/恢复/取消(作废)/删除(硬删) | ✅ |
