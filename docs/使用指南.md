# 雏鹰之翼航模队管理系统 · 使用指南

> 面向全体队员，以及部长 / 管理员。遇到问题先看最后一节「常见问题」。

## 1. 登录

- 浏览器打开队里发的地址（生产环境是 `https://<域名>`，局域网测试是 `http://<服务器IP>:3000`）
- 用**管理员发你的用户名和密码**登录；没有账号就找部长/管理员要一个**邀请码**，在登录页点注册
- 登录状态保存在浏览器里，**换浏览器或清了缓存要重新登录**
- 密码忘了：找管理员在「队员管理」里重置（自己改密码在「我的档案 → 编辑 → 重置密码」）

## 2. 五分钟上手

打开就是**仪表盘**，四张卡 + 四个面板：

- 统计卡：团队成员 / 库存物料（含低库存提示）／库存总价值、本月支出（部长与管理员可见）
- 库存分布（按分类）、低库存预警、团队动态、最近事故
- 右下角**快捷操作**：发起领用 / 上传文档 / 记飞行日志 / 我的档案
- 右下角**悬浮 AI 助手**：任何问题都能直接问它（见第 12 节）

按角色看不同的部分：

| 你是 | 先看这些 |
|---|---|
| 新队员 | 我的档案 → 知识库/Wiki 文档 → 零件库存 → 飞行日志 |
| 一线队员 | 零件领用与归还 → 飞行日志上传 → 事故报备 → 固件下载 |
| 部长 | 上面全部 + 组织架构、考核管理、邀请码、知识库、Wiki 导入 |
| 管理员 | 上面全部 + 系统设置、系统日志、备份恢复、云存储、AI 管理员 |

## 3. 知识库与 Wiki 文档

- **Wiki 文档**：AI 从代码仓库/压缩包生成的文档，按项目列出 → 点进去是「左侧目录 + 右侧内容」
  - 正文里的源码链接可跳到对应文件；翻译过的项目右上角能切「中 / EN」
  - 部长和管理员还有「检查修正」（让 AI 复查格式）与「补齐缺失文档」（见下）
- **知识库**（部长/管理员）：直接读写 `data/knowledge` 下的 Markdown，支持新建文件/文件夹、重命名、下载
- **Wiki 导入**（部长/管理员）：填 Git 地址或上传 ZIP → AI 自动生成整套文档
  - 「生成模型」可以留空用全局默认，也可以**手填任意模型名**
  - 任务队列会显示**阶段 + 进度条 + 当前正在生成的文档**，进行中每 5 秒自动刷新
  - 任务失败或文档缺失时，那一行会出现**补齐缺失文档**按钮

### 文档打不开（显示 404 / 空白）怎么办

这是**生成时文档没真正写出来**的典型表现（任务完成了，但知识库里没有文件）。页面会自动显示：

1. 该文档**在服务器上的完整路径**（例如 `/data/knowledge/公共/项目名/路径.md`）
2. 两个恢复按钮：
   - **从历史版本恢复（免费）**：知识库每次覆盖都会留备份在 `.history/`，直接补回来，**不调用 AI、不花钱**
   - **补齐缺失文档（AI）**：只对缺失的那几篇调用 AI —— 已生成的不会重跑、目录不会重新生成、源码也不会重新下载，**费用只和缺几篇有关**，与仓库大小无关

## 4. 零件库存

> 执行标准（分级、命名、库位、领用归还、盘点、报损、采购"必须怎么做"）见
> **[物料管理规范](物料管理规范.md)**；本节只讲界面怎么用。

- 列表支持按分类/关键词/状态筛选；低库存的物料会高亮（阈值由管理员在系统设置里配，默认「数量 < 5」算不足）
- **库位编码**用「房间 → 货架/柜子等元素 → 层 → 位」逐级选择自动生成（如 `201-A-3-05`），不用手敲
- 部长/管理员可以「添加零件」，也可以「导入 Excel」——表头写 `名称 / 分类 / 数量 / 库位 / 状态`（可选 `等级`、`单价`；填了单价会按 ≥1000→A、100~999→B、<100→C 自动定级）
- 物料状态只有三种：`available` 可用、`in_use` 使用中、`broken` 损坏（"不足"是低库存提示，不是状态；"损坏/遗失"是报备记录）

## 5. 物料布局（房间平面图）

- 以房间为单位画平面图，**单位统一 cm**；可放立体货架、柜子、工作台等元素
- 元素上会显示挂了哪些物料；点元素可看「正视细节视图」（层 × 位 / 层 × 格 / 排 × 区）
- 编辑模式支持拖动、改尺寸、撤销（Ctrl+Z）；保存后库存表单里的库位选择器就会跟着更新

## 6. 领用管理 / 盘点 / 采购

- **领用管理**：选择物料与数量发起领用，归还后回到在库；领用记录可查
- **物料盘点**：生成盘点任务并分配盘点人，逐项核对数量、标记差异
- **采购申请**：队员提交 → 部长/管理员审批 → 购买 → 入库，全流程留痕，支持报表

## 7. 飞行日志 / 固件

- **日志文件**：上传 `.tlog` / `.bin`（管理员可删），下载带进度条，可取消
- **固件下载**：选来源 → 机型（ArduPilot）→ 版本 → 飞控板（可搜索）→ 文件（APJ 推荐 / ABIN / HEX / ELF；PX4 是 `.px4`）
  - 首个下载的人由**服务器回源上游并缓存**，之后全队走本地缓存，秒下
  - 下载过程有进度条，可以取消
- **日志分析**（`日志分析` 菜单）指向 ArduPilot WebTools 工具集（在线看图/分析）

## 8. 事故与安全

记录**电池事故**与**飞行事故**（类型、严重程度、原因、处理、关联飞手/设备）。安全无小事，出了状况当天就登记。

## 9. 资源共享

上传/下载队内文件，任意格式，**单文件最大 1 GB**。大文件建议先压缩。

## 10. 我的档案

- 基本信息：飞手等级、飞行小时、首飞日期、紧急联系人/电话、飞行种类、技能标签、简介
- 培训记录、参赛记录（名称/日期/项目/名次/证书链接）
- 技能认证：由部长/管理员发起**考核**，通过后自动出现在档案里
- 自己可以在「编辑档案」里改信息；角色/部门只有管理员能改

## 11. 通知

右上角铃铛会收到与个人相关的提醒（如任务失败、审批结果）。仪表盘「团队动态」也会列最近的事件。

## 12. AI 助手

- 右下角悬浮按钮随时提问：航模技术、零件参数、操作流程、队内规范……
- 回答**优先引用队内知识库**并标注「来源：文件名」；知识库里没有的会用通用知识并从说明中提示
- 管理员可在「系统设置 → AI 服务」里调整**对话模型名**（可填任意模型名）与**系统提示词**（留空用内置默认；默认已要求纯文本、不用 Markdown 装饰与 emoji）

## 13. 管理员专区

| 功能 | 说明 |
|---|---|
| 系统设置 | AI 模型/提示词、密钥、限流、品牌（队名/主题色）、库存低阈值等 |
| 系统日志 | 请求日志（含来源 IP）+ **操作审计**（谁在什么时候做了什么） |
| 队员管理 / 组织架构 | 账号、角色、部门 |
| 考核管理 | 部门考核与技能认证 |
| 邀请码 | 控制自助注册 |
| 回收站 | 误删内容的恢复 |
| 备份恢复 | 数据库备份/还原；服务器每天还会自动打包 `data/` |
| 云存储 | 百度网盘同步（备份、知识库） |
| AI 管理员 | 自诊断 / 团队分析 / 代码提案（提案需人工批准） |
| Wiki 设置 | 文档生成的模型、并行数、超时、推理模式等 |

## 14. 常见问题

**登录后老是被踢出去？** 多半是 Token 过期或换了浏览器，重新登录即可。

**提示「请求超时/表格加载失败」？** 刷新页面；连续失败找管理员看「系统日志 → 请求日志」。

**密码输错太多次登不上？** 登录有频率限制（同一 IP 每分钟 5 次），等一分钟再试。

**Wiki 文档打不开？** 见第 3 节末尾的两种恢复方式。

**固件下载很慢或失败？** 第一次是服务器去上游取（慢），之后走缓存很快；下载中可以取消重试。若一直失败，把「固件下载失败」的提示原文发给管理员。

**我在手机上能用吗？** 可以，页面做了移动端适配；复杂操作（画平面图、编辑文档）建议用电脑。

**数据存在哪？** 知识库文档在服务器的 `data/knowledge/`（含 `.history` 历史版本），数据库是 `data/teamportal.db`，每天自动打包备份到 `/opt/backups/team-portal/`。详见 `docs/ARCHITECTURE.md`。
