# 标签打印 SDK 接入（精臣 NIIMBOT K3W）

> 状态：代码已接入并通过纯函数/假 WebSocket 测试；**尚未在真机 K3W 上验收**（见文末清单）。
> SDK 来源：官方交付包 `web-4.2.1_20260902`（厂商版本号 4.2.1 / 2026-09-02）。

## 1. 功能与页面入口

物料标签弹窗（库存 → 物料 → 标签）新增「直连打印（精臣 K3W）」区块：

- 连接本机打印服务（`ws://127.0.0.1:37989`）→ 发现 USB 打印机 → 连接 → `initSdk`；
- 按当前标签模板绘制画板 + 元素，并可先生成预览图确认版式；
- `startJob` → 等 `commitJob ok!` → 绘制 → `commitJob` → 打印进度 → `endJob` 完成出纸；
- 失败时给中文原因 + 处理建议，且始终保留「导出 PDF」这条不依赖打印服务的退路。

连接、预览、打印都**只在用户点击时触发**，页面加载不会自动连打印机或自动重试。

## 2. 使用前提（用户电脑）

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 x64（打印服务是 Windows 程序） |
| 打印服务 | **必须安装并启动**：SDK 包里 `打印服务（必须安装）/jcPrinterSdk_4.2.1_20260902.exe`；启动后托盘有图标，监听 37989 |
| 打印机 | 精臣 K3W，开机；热敏标签纸（K3W 只支持热敏，不需要碳带） |
| 连接 | USB（推荐，即插即用）；或 2.4GHz Wi-Fi |
| Wi-Fi 配网 | **必须先用 USB 连接**再写入 Wi-Fi 配置；K3W 不支持 5GHz（配网入口在精臣官方 App/软件里，本页面暂未做配网 UI） |
| 驱动 | Windows 10/11 通常免驱；Windows 7 需安装 SDK 包里的 USB 虚拟串口驱动 |
| 浏览器 | 推荐 Chrome / Edge **154 及以上**（本机 WebSocket 权限协商需要）；旧浏览器改用「导出 PDF」 |
| 网络拓扑 | 打印服务必须在**打开网页的这台电脑**上（页面连的是 127.0.0.1，不是服务器） |

端口自检（PowerShell）：

```powershell
Test-NetConnection 127.0.0.1 -Port 37989
# TcpTestSucceeded 必须是 True；False = 打印服务没装/没启动/被安全软件拦截
```

## 3. 操作步骤

1. 在 Windows 电脑上安装并启动「精臣打印服务」，确认托盘图标存在；
2. 打开系统页面 → 库存 → 选中物料 → 点「标签」；
3. 在「标签模板」里选好版式（K3W 常用 50×30mm，页面会对非 50×30 模板给提醒）；
4. 点「连接打印机」：状态依次变为 连接中 → 已连接：设备名；
5. 点「预览」：确认二维码/文字版式（预览图来自打印服务，和真实出纸一致）；
6. 填份数 → 点「直连打印」：进度会显示启动任务 / 绘制 / 提交 / 正在打印第 N 页第 N 份 / 打印完成。

## 4. SDK 文件来源与 vendor 说明

| 本项目文件 | 上游文件 | 说明 |
|---|---|---|
| `web/lib/niimbot/Socket.ts` | `pc-react/src/Socket.ts` | WebSocket 登录/请求池/事件推送；增加自动重连开关、open 失败 reject、`targetAddressSpace` |
| `web/lib/niimbot/Print.ts` | `pc-react/src/Print.ts` | 打印服务 API 封装；类型修正（参数是对象不是字符串） |
| `web/lib/niimbot/PrintElementFactory.ts` | `pc-react/src/PrintElementFactory.ts` | 元素 → `DrawLable*` apiName 映射 |
| `web/lib/niimbot/protocol.ts` | 上游散落的 interface | 协议类型收窄（无 `any`） |
| `web/lib/niimbot/errors.ts` | `Demo/js/app/client.js` 错误码表 | 错误码 → 中文提示 |
| `web/lib/niimbot/labelMapping.ts` | `Demo/js/printData/fixed_asset.js` 借鉴版式 | 模板 → SDK 单页数据（纯函数） |
| `web/lib/niimbot/client.ts` | `Demo/js/app/operations.js` | 连接/预览/打印生命周期 |

协议字段名是历史拼写（`DrawLableText`、`textAlignHorizonral`、`HorizontalShift`），
**不要「顺手改成正确拼写」**，改服务端会不认。

没有引入任何新 npm 依赖；SDK 客户端是纯 TS 代码，不需要把厂商的打包产物放进仓库。

## 5. 模板 → 打印数据映射

- 模板元素 `x/y/w/h` 单位是 **mm**，SDK 也是 mm，直接透传；
- 字号：模板 `fontSizePt` 是 pt → SDK `fontSize = pt × 25.4 / 72`（mm），12pt ≈ 4.23mm；
- 二维码：内容固定为**短链** `{对外地址}/i/{编码}`，`codeType=31`（QR_CODE）；
- 文本：`textAlignHorizonral` 左/中/右 = 0/1/2，垂直居中 = 1；宽度超框时 `lineMode=6` 自动缩放，关闭 autoShrink 时 `lineMode=4` 裁切；
- 当前模板契约（task-17）只有 `qr` / `text` 两种元素；若模板出现条码/线条/图形/图片，映射会**明确报错并提示改用导出 PDF**，不会静默印出缺元素的标签；
- 画板尺寸 = 模板尺寸；K3W 常用 50×30mm，非该尺寸会在弹窗里提示，但不会强行改模板。

## 6. HTTPS / 混合内容限制（重点）

生产页面是 HTTPS，而打印服务是本机明文 `ws://127.0.0.1:37989`。浏览器可能把它当混合内容拦截。

本项目的处理（`web/lib/niimbot/Socket.ts`）：

1. 优先 `new WebSocket(url, { targetAddressSpace: "loopback" })`：Chrome/Edge 154+ 支持，
   浏览器会弹出「访问本地设备 / 本地网络」权限提示，**用户选择允许后**才能连；
2. 旧浏览器会把第二个参数当子协议而抛错，代码 `try/catch` 后退回 `new WebSocket(url)`；
3. 连接失败时区分提示三种原因：
   - 打印服务没装 / 没启动（连接被拒绝）；
   - 浏览器本地网络权限被拒绝，或浏览器版本太旧不支持 `targetAddressSpace`；
   - 其他（防火墙/安全软件/端口占用）。
   并附 `Test-NetConnection 127.0.0.1 -Port 37989` 自检命令；
4. 任何情况下都保留「导出 PDF」按钮：生成 80×50（或当前模板尺寸）的 PDF，
   用精臣软件/系统打印出纸，不需要浏览器连本机服务。

> 权限提示出现在浏览器顶部地址栏附近，文案类似「此站点想要访问本地网络上的设备」。
> 拒绝后需要点地址栏左侧的站点信息 → 网站设置 → 本地网络/本地设备 重新允许。

## 7. 错误码速查

| 错误码 | 含义 | 处理 |
|---|---|---|
| 1 | 上盖未关 | 合上上盖 |
| 2 | 缺纸 | 装好标签纸、确认纸路 |
| 3 | 电量过低 | 充电 |
| 6 | 打印异常 | 重试 |
| 7 | 打印头过热 | 冷却后再打 |
| 8 | 出纸异常 / 纸用完 | 检查纸张 |
| 9 | 打印机忙 | 等当前任务结束 |
| 13 | 未检测到碳带 | K3W 为热敏，不需要碳带；检查机型/耗材 |
| 16 | 纸张类型错误 | K3W 支持间隙纸/黑标纸/透明纸 |
| 22 | 通讯超时/异常 | 检查打印服务与 USB |
| 23 | 打印机连接断开 | 重新拔插 USB / 重新上电 |
| 30 | 浓度设置异常 | K3W 浓度 1~5 |
| 31 | 打印模式异常 | K3W 只支持热敏（printMode=1） |
| 32/33 | 标签材质异常/不支持 | 更换标签纸 |
| 50/51 | 非法标签/碳带 | 使用正品耗材 |
| -2 | 打印机忙 | 等待或取消任务 |
| -3 | 参数不支持 | 检查浓度/纸张/模式 |

完整表见 `web/lib/niimbot/errors.ts`。

## 8. 故障排查

- **状态一直「未连接」**：先跑 `Test-NetConnection`；确认打印服务是**这台电脑**上运行的；
- **连接被浏览器拦截**：升级到 Chrome/Edge 154+，允许本地网络权限；或直接导出 PDF；
- **搜不到 USB 打印机**：K3W 是否开机、USB 线是否支持数据传输、Windows 设备管理器是否有未知设备、打印服务托盘是否正常；
- **打印卡住/超时**：检查打印机是否开盖/缺纸；页面 60 秒无进度会超时并尝试停止任务；
- **打印内容错位**：模板尺寸与纸不符（50×30 纸张却选了 80×50 模板），换模板后重新预览。

## 9. 卸载 / 回滚

前端回滚（不涉及后端/数据库）：

1. 删除 `web/lib/niimbot/` 目录；
2. 移除 `web/components/inventory/ItemLabelModal.tsx` 里的 `<NiimbotPrintPanel ... />` 与 import；
3. 删除 `web/components/inventory/NiimbotPrintPanel.tsx` 与对应测试；
4. 现有「导出 PDF / 浏览器打印」路径不受影响。

用户侧卸载：控制面板卸载「精臣打印服务」即可；不影响系统里的 PDF 打印。
