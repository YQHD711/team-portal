# 标签打印 SDK 接入（精臣 NIIMBOT K3W）

> 状态：代码已接入并通过纯函数/假 WebSocket 测试；**尚未在真机 K3W 上验收**（见文末清单）。
> SDK 来源：官方交付包 `web-4.2.1_20260902`（厂商版本号 4.2.1 / 2026-09-02）。

## 1. 功能与页面入口

物料标签弹窗（库存 → 物料 → 标签）新增「直连打印（精臣 K3W）」区块：

- 连接本机打印服务（`ws://127.0.0.1:37989`）→ 发现打印机 → 连接 → `initSdk`；连接方式可选 **USB**（`getAllPrinters/selectPrinter`）或 **2.4GHz Wi-Fi**（`scanWifiPrinter/connectWifiPrinter`，见 §4）；
- 按当前标签模板绘制画板 + 元素，并可先生成预览图确认版式；
- `startJob` → 等 `commitJob ok!` → 绘制 → `commitJob` → 打印进度 → `endJob` 完成出纸；
- 失败时给中文原因 + 处理建议，且始终保留「导出 PDF」这条不依赖打印服务的退路；
- 支持**批量连续打印**（物料多选 / 房间或元素的库位标签），详见 §5；直连打印入口**仅部长与管理员**可见。

连接、预览、打印都**只在用户点击时触发**，页面加载不会自动连打印机或自动重试。

弹窗布局：桌面（lg 及以上）为两栏——左栏标签预览 + 模板下拉，右栏打印方式（直连打印 + 浏览器打印/导出 PDF/复制短链）；移动端（< md）单列、操作按钮 2×2，K3W 面板默认折叠成标题行，点标题展开。

### 下载打印服务安装包

面板说明区提供「下载打印服务安装包（Windows，约 37MB）」按钮：走 `GET /api/downloads/print-service`（需要登录态，前端用带 JWT 的 `api.download` 拉 Blob），文件名固定 `jcPrinterSdk_4.2.1_20260902.exe`。下载失败会显示可读原因（401 会由 `api.download` 统一跳登录）。

## 2. 使用前提（用户电脑）

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 x64（打印服务是 Windows 程序） |
| 打印服务 | **必须安装并启动**：可在标签弹窗面板里直接下载安装包（约 37MB），也可用 SDK 包里的 `打印服务（必须安装）/jcPrinterSdk_4.2.1_20260902.exe`；启动后托盘有图标，监听 37989 |
| 打印机 | 精臣 K3W，开机；热敏标签纸（K3W 只支持热敏，不需要碳带） |
| 连接 | USB（推荐，即插即用）；或 2.4GHz Wi-Fi |
| Wi-Fi 配网 | **必须先用 USB 连接**再写入 Wi-Fi 配置；K3W 不支持 5GHz（配网入口在精臣官方 App/软件里，本页面暂未做配网 UI） |
| 驱动 | Windows 10/11 通常免驱；Windows 7 需安装 SDK 包里的 USB 虚拟串口驱动 |
| 浏览器 | 推荐 Chrome / Edge **154 及以上**（本机 WebSocket 权限协商需要）；旧浏览器改用「导出 PDF」 |
| 网络拓扑 | 打印服务必须在**打开网页的这台电脑**上（页面连的是 127.0.0.1，不是服务器） |

常见问题（弹窗说明区同款文案）：

- **K3W 支持 Wi-Fi（仅 2.4GHz）**：首次配网必须先用 USB 连接，在精臣软件/打印服务里完成配网后即可无线打印；同一台电脑仍需安装打印服务。
- **打印服务是浏览器与打印机之间的本机桥接，必须安装**；Win10/11 一般免驱，Win7 需额外安装 K3W 驱动。

端口自检（PowerShell）：

```powershell
Test-NetConnection 127.0.0.1 -Port 37989
# TcpTestSucceeded 必须是 True；False = 打印服务没装/没启动/被安全软件拦截
```

## 3. 操作步骤

1. 在 Windows 电脑上安装并启动「精臣打印服务」，确认托盘图标存在（没装可在标签弹窗里点「下载打印服务安装包」）；Wi-Fi 用户先在官方 App/软件里完成 2.4GHz 配网（见 §4）；
2. 打开系统页面 → 库存 → 选中物料 → 点「标签」；
3. 在「标签模板」里选好版式（K3W 常用 50×30mm，页面会对非 50×30 模板给提醒）；
4. 选连接方式：USB 点「连接打印机」；Wi-Fi 先「搜索 Wi-Fi 打印机」再选设备点「连接」。状态依次变为 连接中 → 已连接：设备名（USB/Wi-Fi）；
5. 点「预览」：确认二维码/文字版式（预览图来自打印服务，和真实出纸一致）；
6. 填份数 → 点「直连打印」：进度会显示启动任务 / 绘制 / 提交 / 正在打印第 N 页第 N 份 / 打印完成。

## 4. Wi-Fi 连接（2.4GHz）

K3W 支持 2.4GHz Wi-Fi，但 SDK 的 Wi-Fi 连接是**另一套 API**，与 USB 不同：

| 步骤 | USB | Wi-Fi |
|---|---|---|
| 发现 | `getAllPrinters` | `scanWifiPrinter`（SDK 侧超时约 25 秒） |
| 连接 | `selectPrinter(name, port)` | `connectWifiPrinter(deviceName, tcpPort)` |
| 初始化 | `initSdk({ fontDir: "" })` | 同左 |

> ⚠️ Wi-Fi 绝不能调 `selectPrinter`：那会把 Wi-Fi 设备当 USB 端口去打开，用户侧表现就是「打印机连接已断开（错误码 23）」。

### 前置条件

1. 先在精臣官方 App/软件里**用 USB 连接**完成 2.4GHz Wi-Fi 配网（K3W 不支持 5GHz）；
2. 打开网页的电脑与打印机在同一局域网/同一网段；
3. 这台电脑仍要安装并启动「精臣打印服务」（浏览器通过本机 ws 桥接，不是直连打印机）。

### 页面操作

1. 物料标签弹窗 →「直连打印（精臣 K3W）」面板；
2. 未连接时选择连接方式 **Wi-Fi**（页面会记住上次选择）；
3. 点「搜索 Wi-Fi 打印机」，等待约 25 秒；
4. 在设备列表里选择设备（显示 deviceName 与 ipAddress），点「连接」；
5. 状态变为「已连接：设备名（Wi-Fi）」后，正常预览/直连打印。

### 常见问题

- **搜不到 Wi-Fi 打印机**：确认配网是 2.4GHz、电脑与打印机同网段、未开 AP 隔离/访客网络；打印机在线并重新上电；Windows 防火墙/安全软件是否拦截打印服务。页面会直接显示这些排查点（`scanWifiPrinter` 返回空数组时）。
- **错误码 23「打印机连接已断开」**：USB 拔插数据线/给打印机重新上电；Wi-Fi 确认打印机与电脑在同一局域网且打印机在线，必要时重新上电后重新搜索连接。
- **Wi-Fi 连上但打印失败**：先确认打印服务托盘在运行；再试「预览」，预览也失败通常是打印服务/SDK 初始化问题，与网络无关。

## 5. 批量打印、库位标签与权限

### 5.1 批量打印（多页连续打印）

- SDK 生命周期：`startJob(count = 页数 × 每页份数)` → 每页绘制 + `commitJob(每页份数)` → 最后一页完成后 `endJob`；进度显示「第 x/N 页」。
- **物料批量**：库存页勾选多个物料（仅 staff 可见复选框/全选）→「批量直连打印（N）」→ 弹窗里选模板、份数、连接打印。短链规则与单张完全一致（`batchLabelData.ts` 单一实现）。
- 没有编码的物料不会生成标签（无编码无法生成二维码）。
- 批量预览只生成第一张（成本考虑），实际会连续打印全部；份数作用于**每一张**，总份数 = 张数 × 份数。

### 5.2 库位标签直连打印

- **房间级**：平面图编辑器 →「直连打印库位标签」（仅 staff）→ confirm 显示张数/跳过数 → 打开批量打印面板；
- **元素级**：元素详情 →「直连打印库位标签」（仅 staff）→ 打印该元素全部真实格位码；
- 编码来源与 PDF 导出完全一致：`roomLocationCodes` → `collectLocationSlots` → `toLocationLabelData`；
- 库位模板走 `resolveLocationExportTemplate`（`kind=location`，无二维码；不适用时回落内置库位模板并提示）。

### 5.3 权限

- 所有**直连打印**入口（物料单个 / 物料批量 / 库位房间级 / 库位元素级）**仅 `admin` 与 `部长` 可见**；非 staff 不渲染入口，不是点了才报错。
- 「导出 PDF」「浏览器打印」保持原有权限不变（本次未收紧）。

## 6. SDK 文件来源与 vendor 说明

| `web/lib/niimbot/errors.ts` | `Demo/js/app/client.js` 错误码表 | 错误码 → 中文提示 |
| `web/lib/niimbot/labelMapping.ts` | `Demo/js/printData/fixed_asset.js` 借鉴版式 | 模板 → SDK 单页数据（纯函数） |

## 7. 模板 → 打印数据映射

- 模板元素 `x/y/w/h` 单位是 **mm**，SDK 也是 mm，直接透传；
- 字号：模板 `fontSizePt` 是 pt → SDK `fontSize = pt × 25.4 / 72`（mm），12pt ≈ 4.23mm；
- 二维码：内容固定为**短链** `{对外地址}/i/{编码}`，`codeType=31`（QR_CODE）；
- 文本：`textAlignHorizonral` 左/中/右 = 0/1/2，垂直居中 = 1；宽度超框时 `lineMode=6` 自动缩放，关闭 autoShrink 时 `lineMode=4` 裁切；
- 当前模板契约（task-17）只有 `qr` / `text` 两种元素；若模板出现条码/线条/图形/图片，映射会**明确报错并提示改用导出 PDF**，不会静默印出缺元素的标签；
- 画板尺寸 = 模板尺寸；K3W 常用 50×30mm，非该尺寸会在弹窗里提示，但不会强行改模板。

## 8. HTTPS / 混合内容限制（重点）

生产页面是 HTTPS，而打印服务是本机明文 `ws://127.0.0.1:37989`。浏览器可能把它当混合内容拦截。

本项目的处理（`web/lib/niimbot/Socket.ts`）：

1. 优先 `new WebSocket(url, { targetAddressSpace: "loopback" })`：Chrome/Edge 154+ 支持，
   浏览器会弹出「访问本地设备 / 本地网络」权限提示，**用户选择允许后**才能连；
2. 旧浏览器会把第二个参数当子协议而抛错，代码 `try/catch` 后退回 `new WebSocket(url)`；
3. 连接失败时区分提示三种原因：
   - 打印服务没装 / 没启动（连接被拒绝）；
   - 浏览器本地网络权限被拒绝，或浏览器版本太旧不支持 `targetAddressSpace`；
   - 其他（防火墙/安全软件/端口占用）。
   并附 `Test-NetConnection 127.0.0.1 -Port 37989` 自检命令；
4. 任何情况下都保留「导出 PDF」按钮：生成 80×50（或当前模板尺寸）的 PDF，
   用精臣软件/系统打印出纸，不需要浏览器连本机服务。

> 权限提示出现在浏览器顶部地址栏附近，文案类似「此站点想要访问本地网络上的设备」。
> 拒绝后需要点地址栏左侧的站点信息 → 网站设置 → 本地网络/本地设备 重新允许。

## 9. 错误码速查

| 错误码 | 含义 | 处理 |
|---|---|---|
| 1 | 上盖未关 | 合上上盖 |
| 2 | 缺纸 | 装好标签纸、确认纸路 |
| 3 | 电量过低 | 充电 |
| 6 | 打印异常 | 重试 |
| 7 | 打印头过热 | 冷却后再打 |
| 8 | 出纸异常 / 纸用完 | 检查纸张 |
| 9 | 打印机忙 | 等当前任务结束 |
| 13 | 未检测到碳带 | K3W 为热敏，不需要碳带；检查机型/耗材 |
| 16 | 纸张类型错误 | K3W 支持间隙纸/黑标纸/透明纸 |
| 22 | 通讯超时/异常 | 检查打印服务与 USB |
| 23 | 打印机连接断开 | USB：拔插线/重新上电；Wi-Fi：确认电脑与打印机同一局域网、打印机在线，必要时重新上电 |
| 30 | 浓度设置异常 | K3W 浓度 1~5 |
| 31 | 打印模式异常 | K3W 只支持热敏（printMode=1） |
| 32/33 | 标签材质异常/不支持 | 更换标签纸 |
| 50/51 | 非法标签/碳带 | 使用正品耗材 |
| -2 | 打印机忙 | 等待或取消任务 |
| -3 | 参数不支持 | 检查浓度/纸张/模式 |

完整表见 `web/lib/niimbot/errors.ts`。

## 10. 故障排查

- **状态一直「未连接」**：先跑 `Test-NetConnection`；确认打印服务是**这台电脑**上运行的；
- **连接被浏览器拦截**：升级到 Chrome/Edge 154+，允许本地网络权限；或直接导出 PDF；
- **搜不到 USB 打印机**：K3W 是否开机、USB 线是否支持数据传输、Windows 设备管理器是否有未知设备、打印服务托盘是否正常；
- **搜不到 Wi-Fi 打印机**：配网是否 2.4GHz、电脑与打印机是否同网段、是否开了 AP/访客隔离、防火墙是否拦截打印服务（页面会显示同款排查点）；
- **打印卡住/超时**：检查打印机是否开盖/缺纸；页面 60 秒无进度会超时并尝试停止任务；
- **打印内容错位**：模板尺寸与纸不符（50×30 纸张却选了 80×50 模板），换模板后重新预览。
