# 移动端适配规范

> 入口页面：队员日常（仪表盘、学习库、Wiki 阅读、零件领用、采购申请、飞行日志诊断）应该能**单手在手机上完成**；
> 重画布类操作（物料布局平面图、标签模板设计器）以桌面为主，手机上保证"能看、能放大、不崩布局"。

## 目标视口与断点

| 断点 | 宽度 | Tailwind 前缀 | 说明 |
|---|---|---|---|
| 手机 | ≤ 639px | 默认样式 | 基准视口 **390×844**（iPhone 12/13/14 的 CSS 宽度） |
| 大手机 / 小平板 | ≥ 640px | `sm:` | 库存表格切回表格布局、双列卡片 |
| 平板 | ≥ 768px | `md:` | 触控下限放宽、部分列显示 |
| 桌面 | ≥ 1024px | `lg:` | 侧边栏常驻、多栏编辑器 |

E2E 回归用 390×844 跑（见 `web/e2e/mobile.spec.ts`）：这个宽度上会暴露的横向溢出、按钮被裁，
在更大的手机上也一样存在。

## 硬性约定

1. **横向不滚动**：任何页面在 390px 下 `documentElement.scrollWidth === clientWidth`。
   长内容要么折行，要么放进 `overflow-x-auto` 容器（表格），不允许把整页顶宽。
2. **栅格子项会收缩**：`grid` 默认列宽是 `auto`，子项 `min-width` 默认 `auto`，
   一个长串就能把整列撑破。移动端已在 `app/globals.css` 里统一：
   ```css
   @media (max-width: 640px) {
     .grid > * { min-width: 0; }
     body { overflow-wrap: anywhere; }   /* pre/code/kbd 例外：保持横滚 */
   }
   ```
   新写的卡片默认就受益；桌面端仍保持单词级断行。
3. **高度用 `dvh`，不用 `vh`**：移动浏览器地址栏伸缩时 `100vh` 会把弹窗/编辑器撑出屏幕。
   弹窗统一 `max-h-[calc(100dvh-2rem)]`。
4. **安全区**：底部悬浮元素（AI 助手按钮、抽屉页脚、弹窗底部）用
   `env(safe-area-inset-bottom)` 让开 iPhone Home 指示条。
5. **触控目标**：`app/globals.css` 在 ≤768px 给 `button` 兜底 40×40px 触控区；
   卡片内并排的紧凑图标按钮显式加 `tap-sm` 退出兜底（否则一行 6 个按钮会把卡片顶破）。
6. **hover 才出现的操作必须可点**：触屏没有 hover。用
   `opacity-100 [@media(hover:hover)]:opacity-0 [@media(hover:hover)]:group-hover:opacity-100`
   的写法（见部门卡片、成员卡片、知识库目录树）。
7. **表格**：宽表格放 `overflow-x-auto`，隐藏掉非关键列（`hidden md:table-cell`）；
   单元格里的长文本用 `line-clamp-2 break-all` / `break-words`，
   **不要用 `truncate`** —— `truncate` 带 `white-space: nowrap`，会把表格的 min-content 撑大，
   结果整张表比屏幕还宽，只能横向拖。
8. **抽屉式导航**：`lg` 以下侧栏是抽屉（遮罩 + 锁 body 滚动 + Esc 关闭 + 路由变化自动收起）；
   Wiki 阅读页的目录同理，进入时默认收起，选中文档后自动收起。

## 已知的桌面优先功能

- 物料布局平面图（Konva 画布）：手机可查看、可缩放，拖拽摆放元素建议用桌面。
- 标签模板设计器：手机上可预览与改数值，精细对齐建议用桌面。
- WebTools 日志分析：第三方静态站，按原样内嵌，不做改造。

## 怎么验证

```bash
# 1) 类型 + 构建
cd web && npm run build

# 2) 移动端回归（真实浏览器，390×844，全部接口走 mock）
cd web && npx playwright test e2e/mobile.spec.ts

# 3) 人工抽查：起后端 + 前端，手机同网段访问，看这几页
#    /  /study  /wiki/<id>  /inventory  /finance  /profile  /flightlog  /admin/organization
```

改动前端布局后，如果新增了"长内容卡片""宽表格""固定高度面板"，
请在 `web/e2e/mobile.spec.ts` 的 `routes` 里补一条对应路由，防止以后又滚出屏幕。
